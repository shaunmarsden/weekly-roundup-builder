# Human Review Checklist

Run through this before acting on anything the roundup suggests.

- [ ] Any trend claim is backed by a genuine earlier report, not a single week's data
- [ ] A missing section was not filled with an estimate to avoid it looking empty
- [ ] A genuine zero is reported as a confirmed zero, not left looking like a missing figure, and vice versa
- [ ] Priorities are specific to what this period's data actually showed, not generic advice
- [ ] Nothing already analysed elsewhere was silently re-derived from scratch
