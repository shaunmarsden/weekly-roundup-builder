# Worked Example

A made-up freelance designer's first weekly roundup. It tests missing versus zero, both ways round, and the rule against claiming a trend in week one.

- [inputs.md](inputs.md): what the designer gathered this week, including one confirmed zero and one missing figure
- [output.md](output.md): the roundup [SKILL.md](../SKILL.md) produced
- [review.md](review.md): whether it told missing from zero both ways round, and whether it claimed a trend where none was possible

The repository doesn't record which model wrote this roundup, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
